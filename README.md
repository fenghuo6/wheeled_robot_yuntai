# 云台控制系统（wheeled_robot_yuntai）


| a | GM6020（ID 5，直驱） | **yaw**，水平旋转 |
| b | GM6020（ID 6） | **折叠轴**，遇障碍时向后折叠避让 |
| c | M2006 + C610（ID 7，36:1） | **pitch**，俯仰 |

核心能力：以 IMU 世界系姿态作为反馈，让 yaw / pitch 跟踪一条 680 ms 周期的闭合轨迹，并按比赛容差实时统计命中率；同时具备红外避障折叠、遥控器三档操作、失能 / 过热 / 接收机掉线保护，以及上位机波形输出。


##  功能总览

| 功能 | 说明 |
| --- | --- |
| 轨迹跟随 | yaw / pitch 以 IMU 世界系姿态闭环跟踪 `trajectory_task` 的曲线 |
| 自动对齐 | 进入跟随时先限速对齐到轨迹起点，到位并保持 200 ms 后才放行轨迹 |
| 双模反馈 | 每轴可独立选择「IMU 世界系跟随」或「编码器锁位（顶住）」 |
| 红外避障折叠 | 障碍进入 50 cm → 折叠 → 停留 3 s → 自动复位，带回差重新武装 |
| 遥控器操作 | 右开关三档：测试跟随 / 自动跟随 / 失能 |
| 安全保护 | 总失能、过热（>80 ℃）保护、DBus 掉线 fail-safe（三档可配） |
| IMU 零偏标定 | 上电采集 1 s 静止样本估计陀螺零偏，并重新冻结 yaw 零点 |
| 比赛计分 | yaw 容差 0.5°、pitch 容差 1.5°，1 s 时间常数的命中率 |
| 波形观测 | 7 通道 @100 Hz：命中率 / 目标 / 实际 / 红外距离 |
| 运行期调参 | 全部参数为 `volatile` 全局量，调试器直接改，1 ms 内生效 |



### 姿态解算（`imu_task.cpp`）

1. 上电后累计 **1000 个静止样本**（三轴角速度 < 0.05 rad/s ≈ 2.9 °/s）估计陀螺零偏，约 1 s；3 s 内采不满则用已有样本兜底，不会永久卡住启动流程。
2. 标定完成瞬间把当前 yaw 冻结为新零点，顺带消掉标定期间积累的漂移。
3. 之后从测量中扣除零偏，交给 Mahony 解算，输出世界系 `g_yaw_rad` / `g_pitch_rad` / `g_roll_rad` 与时间戳 `g_imu_update_ms`。
4. 未标定时 yaw 漂移典型 0.1~0.5 °/s，标定后 0.01~0.05 °/s。**零偏必须在运动前标定完成**：否则 yaw 单向漂移会让环路持续单方向出力，最终表现为线缆缠绕。

> IMU 数据超过 `IMU_STALE_TIMEOUT_MS = 50 ms` 未更新即判失效，反馈冻结时误差不再变化、环路会一直死推，因此 `motor_task` 会立刻停止 a/c 输出。


###  跟随启动（`motor_control.cpp`）

- 对齐阶段以**当前姿态**为起点，按 `g_cfg_align_rate_dps`（默认 23 °/s）限速逼近轨迹起点，避免切换瞬间跳变；
- 到位容差 `g_cfg_align_tolerance_deg`（默认 3°），需连续保持 200 ms；
- 超时 `g_cfg_align_timeout_ms`（默认 4 s）强制放行，防止机械到不了目标时永久卡住；
- **只检查正在跟随的轴**：某一轴掉线不会拖累另一轴的对齐；
- 只有进入 `kFollow` 后 `g_traj_following = true`，前馈和命中率统计才使能（对齐阶段误差恒 0，统计会被刷高）。



### 折叠轴（`motor_control.cpp` 状态机）

- **只折一次**：整条序列跑完一遍后请求保持 true 也不会重复折叠（`g_fold_ran` 锁存），想再折必须先调 `false` 再 `true`；
- **红外自动触发**（`ir_fold_update()`，`g_cfg_ir_trigger_cm` 默认 50 cm）：
  - 前提：GY-56 在线且测距状态「可靠」（0），否则旧值会误触发；
  - 跟随期间**关闭**折叠触发，正在跑的序列正常走完；
  - 序列结束后不自动开始轨迹跟随；
  - 次数统计在 `g_ir_fold_count`。
- 折叠期间 a/c 一律不跟随：IMU 装在折叠关节下游，b 一动世界系姿态整体变化。


### 遥控器右开关三档

| 档位 | 行为 |
| --- | --- |
| **UP（测试档）** | 立刻开始 yaw + pitch 跟随，用于验证整条链路 |
| **MID（自动档）** | 等折叠复位完成（`g_fold_phase == 4`）后延时 `g_cfg_auto_follow_delay_ms`（默认 3 s）再跟随；没折过不跟随 |
| **DOWN（失能档）** | 三轴全松，折叠流程清零，优先级最高 |
